# Data Specification

**Dataset**: `ARTPARK-IISc/Vaani-Noise-Event-Dataset` (Hosted on Hugging Face).
**Total Duration**: ~154.6 hours.

## Annotation Tiers
1. **Gold**: ~21.8 h, verified clean timestamps.
2. **Silver**: ~100.32 h, timestamped but less verified.
3. **Bronze**: ~32.42 h, noise tags only, no timestamps.
